# Lunar Horizon Productions website

Everything you will ever edit is inside the `content/` folder (never open `index.html`, `style.css` or `site.js`), and to edit a file there right-click it and choose Open with, then Notepad, because double-clicking a `.js` file makes Windows try to run it and show an error like 800A03F6, and every file there starts with a ✏️ banner, uses plain `Name: words` lines, and has a few characters you must never delete: the colon after each name, the `|` in navigation lines, the blank line between entries, and the backtick (`` ` ``) at the start and end of the text. To **edit existing text**, open `content/site-text.js` for the top bar, headline, footer, start-up screen and comms intro, `content/navigation.js` for button names, or the list file an entry lives in (`manifest.js`, `captains-log.js`, `comms.js`); to **edit existing images**, put the picture in `content/images/` and change the `Image:` line of its entry in `content/manifest.js` (or in a page file), or the `Hero image:` line in `content/site-text.js` for the logo at the top of the page; to **add a manifest entry** open `content/manifest.js`, to **add a captain's log entry** open `content/captains-log.js`, and to **add a comms entry** open `content/comms.js`, copying the TEMPLATE lines at the top of each, removing the `#` marks and leaving a blank line between entries; to **add a new page** duplicate `content/pages/TEMPLATE-page.js`, rename the copy (for example `about-us.js`) and write your sections; to **add that page to the navigation** open `content/navigation.js` and add the single line `ABOUT US | about-us`, where the part after the `|` is the file name without `.js`.
