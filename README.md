# Lunar Horizon Productions website

Everything you will ever edit is inside the `content/` folder (never open `index.html`, `style.css` or `site.js`), and to edit a file there right-click it and choose Open with, then Notepad, because double-clicking a `.js` file makes Windows try to run it and show an error like 800A03F6, and every file there starts with a ✏️ banner, uses plain `Name: words` lines, and has a few characters you must never delete: the colon after each name, the `|` in navigation lines, the blank line between entries, and the backtick (`` ` ``) at the start and end of the text. To **edit existing text**, open `content/site-text.js` for the top bar, headline, footer, start-up screen and comms intro, `content/navigation.js` for button names, or the list file an entry lives in (`manifest.js`, `captains-log.js`, `comms.js`); to **edit existing images**, put the picture in `content/images/` and change the `Image:` line of its entry in `content/manifest.js` (or in a page file), or the `Hero image:` line in `content/site-text.js` for the logo at the top of the page; to **add a manifest entry** open `content/manifest.js`, to **add a captain's log entry** open `content/captains-log.js`, and to **add a comms entry** open `content/comms.js`, copying the TEMPLATE lines at the top of each, removing the `#` marks and leaving a blank line between entries; to **add a new page** duplicate `content/pages/TEMPLATE-page.js`, rename the copy (for example `about-us.js`) and write your sections; to **add that page to the navigation** open `content/navigation.js` and add the single line `ABOUT US | about-us`, where the part after the `|` is the file name without `.js`; to **change a button icon** open `content/icons.js` and type an emoji, a symbol or a picture file name (pictures go in `content/images/`) after the colon of the button you want (leave it empty for the glowing dot, or type `none`), and any comms or page entry can also have its own `Icon:` line; to **change a sound** put an mp3, wav or ogg file in `content/sounds/` and type its file name after the colon of that sound in `content/sounds.js` (add `| 60` after the name to make it quieter, leave it empty for the built-in sound, or type `off` for silence); to **change how a button looks** put a picture in `content/images/` (or a short animated gif, webp or png in `content/animations/`) and type its file name after the colon of that button's `on` or `off` line in `content/buttons.js` (a `loop animation` line repeats while the button is on, an `on animation` or `off animation` line plays once when the button switches on or off with its length in seconds typed after a `|`, a `words: hide` line hides the button's words, a `size: 120 x 48` line sets the button size in pixels, and an empty line keeps the current look).
